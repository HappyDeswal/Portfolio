Offlinenotes, reading and focus tools

The problem

Study workflows often require separate tools for reading, note-taking and time management.

What I built

I built a single-page app with Markdown notes, a Pomodoro timer, text-to-speech, animated themes, cloud sync and an IndexedDB fallback.

The result

Core tools can run offline. Notes can be exported as Markdown or ZIP files without a server.
