Project illustration

~1.1%MAE on a 300-row dataset

The problem

Comparing regression models on spreadsheet data can take repeated manual work and requires code.

What I built

I built a desktop app that reads Excel data, trains Gaussian Process models, and compares four kernels using leave-one-out cross-validation. The Excel report includes predictions and 95% confidence intervals.

The result

On a 300-row dataset, mean absolute error fell from about 5.5% to 1.1%.
